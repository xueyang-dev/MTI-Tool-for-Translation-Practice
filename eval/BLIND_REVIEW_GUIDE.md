# Blind Review Guide（盲评指南）

感谢参与评审。本包由 **80 对**译文组成，每对包含：

- `source`：原文段落
- `candidate_a` / `candidate_b`：两个系统各自产出的译文

## 评审须知

- **你不知道 candidate_a / candidate_b 分别来自哪个系统**，也不需要知道。
  映射关系单独保存在 key 文件中，只有实验组织者能看到。
- 请逐对独立判断，不要因为前后段的一致性而互相影响（除非确属同一段）。
- 不要试图猜测"哪个是新的"；只根据译文本身质量判断。

## 评分字段（每对两条 candidate 各评一次）

错误字段取值：**0 = 无错误；1 = 有错误**。无法确定时填 0 并在
`reviewer_note` 说明。

- **terminology_error**：专业词、专名、术语是否使用恰当/统一（如飞机型号、
  人名、地名、军职称谓等）；与候选译文内部一致性无关，只看术语本身是否合适。
- **fidelity_error**：是否忠实表达原文（意思漏掉、添改、曲解、数字/引语失真）。
- **fluency_error**：中文自然度与可读性（语序、搭配、标点、可理解性）。
- **omission**：是否存在明显漏译（整句/整段缺失，或关键信息被吞）。
- 同一处问题可以同时计入多个字段（例如漏译通常同时是 fidelity 与 omission）。

## overall_preference

- **A**：candidate_a 整体更可接受。
- **B**：candidate_b 整体更可接受。
- **Tie**：两者同等可接受（或各有问题、难分高下）。

不要因为单纯的措辞差异强行二选一；只要两者都忠实、通顺、术语合理，选 **Tie**。

## 提示

- 优先看"有没有错"，再看"哪个更好"。
- 文学性表达没有唯一正确答案；只要不违背原文且中文自然，都是可接受的。
- 某一对中如果两个候选完全相同，直接按共同质量评价并可选 Tie，不必纠结。

填写完成后请把 packet CSV 交回实验组织者；**不要**把 key 文件与评审结果一起发送。
