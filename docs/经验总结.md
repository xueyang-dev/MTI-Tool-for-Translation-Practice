# MTI-Tool 实战经验总结与内部规约

本文档沉淀自《When the Sky Was Ours》全书翻译实战（224 页 / 3389 段）中踩过的坑，
每条都对应一次真实事故。**新增或修改代码前请先读一遍**，避免同类问题复发。

---

## 教训 1：分段/清洗必须确定性，不能交给 LLM 自由裁量

**事故**：旧版把 ~2500 字符的任意文本块交给大模型"清洗"，块边界落在句中就把句子
劈成两半（"…pecking at" / "crumbs and bones like a turkey."）；模型对引语、对白
随意拆分合并，全书出现 36 段碎句，分段结果不可复现。

**规约**：PDF 提取一律走 `extract_pdf_paragraphs`（版面结构：块→行→首行缩进判段落，
连字符修复、跨页合并、页眉页脚/页码剔除全部确定性完成）。LLM 只做翻译，不做版面理解。

## 教训 2：大模型返回格式永远不可信，解析要宽容、兜底要设下限

**事故**：DeepSeek 返回过编号行、`{"1": ...}` 对象、`[{"translation": ...}]` 对象数组，
甚至把 JSON 原文当译文输出；单段兜底曾把 `[{"译文": "甲"}, 42]` 整段当译文吞掉。

**规约**：所有解析入口统一走 `parse_json_array` / `parse_translation_array`；
单段兜底必须拒绝"形似 JSON"的响应；新形态先补解析器，再补测试
（`test_parse_translation_array`）。

## 教训 3：LLM 输出必须过确定性校验，失败要自动修复或回滚，不能只记录

**事故**：审校环节把模型建议的"修正句"整段替换长段译文，复验只查保留项不查完整性，
全书 136+ 段被截断成一句（600 字符原文只剩"富加·马吉斯特教练机装备了火箭弹。"）。

**规约**：`check_translation_batch` 内置完整性检查（字符比 + 句数比双规则，含缩写豁免）；
审校建议先应用→复验→不过则回滚；修复结果不允许比原译文更不完整。

## 教训 4：翻译记忆是错误放大器，入库门槛必须严格

**事故**：一个 `*` 装饰行被误译成"我脸红了。"，通过审校进了翻译记忆，随后全书 23 处
`*` 全部精确命中复制同一错译。

**规约**：
- `_tm_eligible`：源文必须有字母/数字、译文非空，否则禁止入库；
- `load_tm` 加载即自清洗，非法/过期条目自动丢弃（防止旧文件污染新任务）；
- 纯符号段落不调用模型，原样保留（`translate_stage` 直通）。

## 教训 5：装饰性文本在提取层剔除，不进入翻译

**事故**：章节分隔符 `*`、`* * *` 被当作正文段落翻译。

**规约**：`_ORNAMENT_RE` 在行级过滤（PDF 与 DOCX 分支一致），且必须在跨页合并
**之前**剔除，否则装饰符会被并进正文段落。

## 教训 6：判断/标注类任务同样要确定性过滤

**事故**：标注模型把 production/grin/rooster/speedily 当"生僻词"标红，把
"Grandma Sarah and Grandpa Yaakov"、"Translation from Hebrew"当"专业名词"标黄。

**规约**：LLM 标注输出必须过 `_clean_annotations` 确定性过滤：
- rare：单 token、≥4 字符、不在 14k 常用词表（含词形还原 speedily→speedy）、
  全书出现 <8 次；
- domain：称谓+人名模式、全常用词短语拦截；
- 术语表覆盖（note 以"术语："开头）不过滤，它是确定性的来源。

## 教训 7：长任务必须断点续传，且断点粒度要稳健

**事故**：标注阶段曾一次跑 400/425 批后被杀，因只在结束时落盘而全部丢失；
断点若按"批次号"记录，批大小调整后会串位。

**规约**：翻译、标注、报告生成全部每批落盘；标注断点按"已处理段数偏移"记录
（`annotations_done_offset`），与批大小解耦；限流必须退避重试（`is_rate_limited`）。

## 教训 8：JSON 落盘后键类型会变（int→str），访问前必须归一化

**事故**：标注字典 `{0: [...], 1: [...]}` 存盘再加载后键变成 `"0"`/`"1"`，
`pairs_to_word` 用 int 索引取不到任何标注，三种颜色全部丢失（曾两次踩坑）。

**规约**：所有消费标注的地方统一走 `_normalize_annotations`（键转 int、越界/非列表
丢弃）；state 字段访问一律 `get`，不假设旧版本存在该键。

## 教训 9：短输入是自动检查的盲区

**事故**：`*`（1 字符）既过不了完整性检查（只查长原文），也没有保留项可查，
错译轻松通过审校。

**规约**：短输入不做例外处理——符号段直通、TM 资格门槛、审校保留；需要新增
针对短段的质量防线时，先评估是否会误伤正常短句（如 "I blushed."）。

## 验证清单

任何改动合入前必须通过：

```bash
.venv/bin/python tests/smoke_test.py   # 28 组冒烟测试
.venv/bin/python tests/app_boot_test.py # Streamlit 启动
```

涉及标注渲染时，额外检查生成的 docx 中三种颜色与字体是否真实出现：
`document.xml` 应包含 `w:val="C00000"` / `BF8F00` / `008080` 与 Times New Roman/宋体声明。
